# 0.6: New note in Single page app diagram

The user is on https://studies.cs.helsinki.fi/exampleapp/spa, writes a note and clicks **Save**.

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note left of browser: User writes a note and clicks "Save". The onsubmit handler in spa.js calls e.preventDefault(), so the browser does NOT submit the form itself.

    Note left of browser: spa.js creates { content, date }, pushes it into the local notes array, clears the input and redraws the notes list in the DOM right away.

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa (Content-Type: application/json, body: {"content": "...", "date": "..."})
    activate server
    Note right of server: Server parses the JSON body and pushes the note into the in-memory notes array
    server-->>browser: 201 Created
    deactivate server

    Note left of browser: No redirect and no page reload: the browser stays on the same page and makes no further requests. The callback only logs the response (on 400 the note would be removed from the list again).
```

Compared to the traditional app, creating a note costs a single HTTP request instead of five, and the page is never reloaded.
